확인·자료 요청

아래 항목을 확인해 주시면 홈페이지 연동과 등록 운영을 이어서 진행할 수 있습니다.

번호 구분 요청 내용 현황 용도

프로그램·연자 관리 화면 안내

목적

  • 세션·연자·CV·초록 파일을 관리 화면에 등록하면 홈페이지 프로그램 화면에 연동되도록 준비합니다.
  • 홈페이지에 실제 반영은 필드·사용 방식 확인 후 진행합니다.

접속

  • 주소: https://ksers-web-production.up.railway.app/service/login.php
  • 관리자 계정으로 로그인 → 메뉴 「프로그램·연자」

등록 방법

  • 화면에서 세션 추가 → 좌장 → 발표·연자 입력
  • 또는 CSV로 일괄 등록 (관리 화면에 양식 제공)
  • 사진, CV(PDF), Abstract(PDF)는 발표별로 파일 업로드

입력 항목 (2026 홈페이지 기준)

  • 세션: ID, 카테고리, 코드, 제목, 날짜, 시간, 룸, 색, 공개 여부
  • 좌장: 이름, 소속
  • 발표·연자: 코드, 제목, 연자명, 소속, 국가, 사진·CV·Abstract

참고

  • 세션을 한 번 등록하면 Program at a Glance(시간표)와 Scientific Program(상세)이 같은 데이터를 사용합니다.
  • 사이트에 공개할 데이터는 이 관리 화면에 올려 주시면 됩니다.
